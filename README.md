# All A's Courses

Public course catalogue for All A's. The site is a static HTML, CSS, and JavaScript application.

## Run locally

Serve this directory with a local HTTP server, for example:

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000` in a browser.

## Structure

- `index.html` — page entry point
- `css/` — styles
- `js/` — application, translations, course data, and registration links
- `assets/` — images and logos

The production site is available at [courses.alphaedtech.com](https://courses.alphaedtech.com).
